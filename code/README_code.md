# Código

Código Python de la aplicación, con sus puntos de entrada, modelos y utilidades.

- [app/](app/README_app.md): puntos de entrada y arranque de la aplicación.
- `services/`: operaciones de datos.
- [repositories/](repositories/README_repositories.md): persistencia
  por entidad.
- [database/](database/README_database.md): conexión y operaciones
  transaccionales para PostgreSQL.
- [models/](models/README_models.md): objetos de datos compartidos.
- [utils/](utils/README_utils.md): configuración y logs.

El reparto de responsabilidades se documenta en
[Arquitectura de software](../documentation/LaTeX/chapters/arquitectura_software.tex).
