# Objetos de datos

Dataclasses inmutables de fondos (`Fund`), proveedores (`DataSource`), asociaciones
(`FundSource`) y valores liquidativos (`FundNav`). Representan los datos del modelo,
sin ejecutar consultas ni escrituras.


`CollectionTarget` agrupa un fondo, sus rutas `CollectionSource` y la última fecha para la que se ha recogido información de NAV.
