# Operaciones de desarrollo

Esta carpeta reúne las guías y herramientas para preparar y utilizar el entorno
local de desarrollo del proyecto en Linux o WSL. Sirve como referencia para
instalar las dependencias, ejecutar y comprobar el código y administrar las
tablas y los datos de la base de desarrollo.

Para trabajar con este entorno, sigue la guía de preparación y consulta después
la operación que necesites. Los comandos de las guías se ejecutan desde la raíz
del repositorio.

## Guías de trabajo

- [Preparar el entorno](entorno_desarrollo.md): descargar el repositorio, crear el entorno virtual e instalar las dependencias.
- [Gestionar la base de datos](base_datos_desarrollo.md): crear tablas, importar el catálogo, vaciar datos y eliminar tablas y vistas.
- [Ejecutar la aplicación y las pruebas](ejecucion_desarrollo.md): arrancar la aplicación y ejecutar pruebas unitarias, de integración o ambas.

## Herramientas de apoyo

- [credentials/](credentials/README_credentials.md): configuración y carga de credenciales de desarrollo desde Bitwarden.
